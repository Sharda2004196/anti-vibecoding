# Contributing to Anti VibeCoding

Thank you for your interest in contributing!

## How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs or suggest features
- Include as much context as possible (Claude Code version, OS, etc.)
- For bugs, provide steps to reproduce

### Pull Requests
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Test your changes
5. Commit with clear messages: `git commit -m "Add: description"`
6. Push to your fork: `git push origin feature/your-feature-name`
7. Open a Pull Request

### Code Style
- Follow existing markdown conventions
- Keep SKILL.md clear and concise
- Use bullet points for readability
- Add examples where helpful

### Areas for Contribution
- Improve templates (PRD/TSD)
- Add new workflow phases
- Enhance documentation
- Fix typos or unclear instructions

## Questions?
Open an issue for discussion before starting major changes.
